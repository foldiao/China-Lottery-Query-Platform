# 开奖数据实验室

一个只依赖 Python 标准库的本地交互网页。支持双色球、超级大乐透、福彩3D、排列3和快乐8；可从福利彩票/体育彩票官方公开接口自动下载历史开奖数据，也可导入 CSV 或 Excel（`.xlsx`）文件，查看号码频次与香农熵，并按平滑后的贝叶斯后验生成随机参考号码。开奖数据保存在 `draws.json`，生成过的号码单独保存在 `tickets.json`。

## 启动

```powershell
python app.py
```

程序会打开 `http://127.0.0.1:8787`。需要换端口时可运行 `python app.py --port 8899`（将 `8899` 替换为所需端口）；同一局域网访问可运行 `python app.py --host 0.0.0.0`。按 Ctrl+C 停止。

## 导入格式

文件首个工作表或 CSV 的列顺序：期号、开奖号码（各号码分列）。例如：

```csv
期号,红球1,红球2,红球3,红球4,红球5,红球6,蓝球
2025001,01,05,12,18,26,33,09
```

支持双色球 6+1、大乐透 5+2、福彩3D和排列3各3位、快乐8的20个号码。程序会按期号去重，重复导入会更新同一期记录。

## 统计方法

页面显示每个号码在导入历史中的出现次数，以及 Shannon 熵 `H = -Σ p(x) log₂ p(x)`。生成号码时使用对称 Dirichlet 先验 `α=20`，号码后验为 `(count + α/K) / (N + α)`，再按后验权重随机抽取；乐透类号码按不重复方式抽取。3D、排列3保留位置并允许重复。

生成页默认勾选“排除最近一期开奖号码”，也可以取消勾选；每个号码区还可手动填写排除号码，支持逗号或空格分隔。3D/排列3的最近一期数字会在三个位置统一排除。

每次生成的号码会保存，并绑定到生成时已知的最近期号之后的第一期开奖。导入或下载包含新期开奖的数据时，网页会自动结算并列出开奖号码、命中数、奖级和可核算奖金。核对区默认显示最近一期，也支持总览、按期号和按日期筛选；总览会统计生成数、已结算数、中奖注数和可核算模拟奖金。官方同步的数据会记录开奖日期，旧的已结算记录在再次同步后可补齐日期。金额按一注2元单式投注模拟、显示税前金额，不表示实际购票或兑奖。快乐8可选择“选一”到“选十”；选九全中与选十全中属于浮动奖，数据未提供该期实发金额时会显示待核实。历史文件若不含奖金级别数据，浮动奖也会提示待核实。

彩票开奖结果若由公平且独立的抽取机制产生，过去的频率不会改变下一期的真实概率。贝叶斯平滑能稳定小样本估计，但不会让历史开奖预测更准确。页面生成结果仅供统计学习和娱乐，不构成投注建议。

## 数据来源

历史数据面板的“自动下载/更新开奖数据”按钮会从中国福利彩票公开开奖接口同步双色球、福彩3D、快乐8；从中国体彩网公开历史开奖接口同步大乐透、排列3。启动程序后会在后台检查全部五个品种；本地没有该品种数据时下载完整历史，已有数据时只拉取最近记录补齐更新。程序持续运行时，会在开奖时间后约5分钟开始检查，未发现当期号码时每15分钟重试，最多约100分钟：双色球周二、四、日21:15；大乐透周一、三、六21:25；福彩3D每日21:15；排列3每日21:25；快乐8每日21:30（使用电脑本地时间）。页面会显示总体百分比、当前彩种和已读取页数；手动下载也会显示进度。自动同步成功后页面会刷新数据与核对结果。完整历史首次下载可能需要一些时间，分页进度按接口分页上限估算，提前结束时会直接完成。网络访问可能受官方站点限流或防护影响，失败时可稍后重试或导入文件；程序关闭期间不会运行定时任务，下次启动会再次补齐最近记录。页面也提供对应的官方开奖页入口。
## 新增的历史滚动回测

页面新增“历史滚动回测”：按期号顺序逐期回测，每个测试期仅使用此前数据计算贝叶斯号码权重，并与均匀随机选号的理论命中基准比较。默认最多展示最近 500 期，至少保留最早 100 期作为训练历史（数据不足时自动调整）。回测值只用于评估历史拟合，随机彩票各期独立，不能据此推断下一期更容易中奖。

## 神经网络训练与时间顺序回测

安装 Python 3.10 或更新版本即可运行，使用标准库，不依赖 PyTorch/NumPy：`python neural_backtest.py`。结果保存到 `neural_backtest_results.json`。也可启动网页后选择彩种，点击“训练神经网络并运行时间顺序回测”。

程序按期号排序，以最早 80% 数据训练、最后 20% 做一次固定留出测试；网络输入只包含目标开奖前最近 5 期与 20 期的号码频率。每个测试期用网络排名前 k 个号码计算命中数，同时与理论均匀随机基准及只用当期之前数据更新的贝叶斯频率排名比较。报告 95% 配对 bootstrap 区间；训练轮数和特征窗口固定，不根据测试集调参。评估结束后再用全部历史训练模型并给出下一期候选号，该建议没有测试保障。

神经网络是纯 Python 单隐藏层 MLP。单次留出实验不能证明彩票可预测；若网络没有显著胜过随机基准，应按未证明有效解释。

## 开奖前预测与对照组

页面的开奖前预测区会为当前彩种生成神经网络、贝叶斯和均匀随机三组预测。同一基准期只保存一次不可修改的快照。

记录单独保存在 `forecasts.json`，与已生成的号码和训练回测结果分开。导入或同步新开奖后自动结算。只有预测日期早于开奖日期的记录进入前瞻对照统计。相同基准期重复点击时保留原快照。

配对差值至少积累到30个独立开奖期，才显示95%配对bootstrap区间。

## 号码排行与模拟频率

排行页会分别列出神经网络与贝叶斯的组内分数排名。神经网络分数没有概率校准保证、且不是下一期的真实概率。

模拟开奖页可选均匀随机、贝叶斯或神经网络作为模拟权重来源、设置模拟次数并统计号码频次。
模拟结果保存在 `simulation_frequencies.json`。号码生成区可选用最近模拟频率作为权重。频率基于有限次数的模拟统计、并使用加一的平滑值保留可选号码。更新开奖数据后旧模拟频率不能用于生成号码、需重新运行模拟。
